# Lumino

Lumino Tech Solutions – A modern digital solutions and technology website.

A responsive studio website showcasing Lumino's design, branding, development, and digital growth services. The site includes animated hero typography, service and project showcases, a process overview, and contact sections.

## Technologies

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lenis
- Lucide React
- Vercel

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
